# Creator Daily Loop

Automated content trend dashboard — multi-platform topic monitoring for content creators.

Daily auto-fetch from Xiaohongshu, Douyin, Bilibili & Baidu trending topics. PushPlus notification delivery.

## Pipeline

Fetch → Filter → Rank → Summarize → Push

## Key Features

- 4-platform concurrent scraping (Xiaohongshu, Douyin, Bilibili, Baidu)
- AI-powered topic summarization & trend analysis
- Configurable keyword filtering per platform
- Daily PushPlus notification with top trends
- Vite-powered dashboard for manual browsing

## Stack

TypeScript · Vite · Claude Code Cron · PushPlus · OpenCLI
